# تصور تنبيه Telegram (غير مُفعّل — يحتاج موافقة)

الهدف: رسالة إلى مجموعة/قناة إدارية عند حفظ مشاركة جديدة، حتى لو كانت لوحة الإدارة مغلقة.

## المسار المقترح (مجاني، بلا خادم إضافي)
1. **Supabase Database Webhook** على `INSERT` في الجدولين `status_updates` و `tickets`
   (Database ← Webhooks). يُطلق بعد نجاح الحفظ فقط.
2. الـ Webhook يستدعي **Edge Function** باسم `notify-telegram` (الكود المقترح في
   `supabase/functions/notify-telegram/index.ts` — غير منشور).
3. الدالة ترسل عبر Telegram Bot API إلى `chat_id` الإداري.

## الأسرار (لا تدخل الكود ولا Git ولا Vercel)
تُحفظ في Supabase ← Edge Functions ← Secrets فقط:
- `TELEGRAM_BOT_TOKEN` — من @BotFather بعد إنشاء البوت.
- `TELEGRAM_CHAT_ID` — معرّف المجموعة الإدارية.
- `WEBHOOK_SECRET` — نص عشوائي طويل يُرسل في ترويسة الـ Webhook لمنع استدعاء الدالة من أي جهة أخرى.

## تقليل البيانات الشخصية
الرسالة تحتوي النوع + رقم المرجع + التصنيف + وقت الإرسال فقط، **بدون اسم أو بريد أو وصف**.
التفاصيل تُفتح من لوحة الإدارة. Telegram خدمة خارجية، فلا تُرسل إليها بيانات المستقلين.

## الحماية من الإزعاج
الإرسال العام محدود أصلًا (10 مشاركات/بريد/ساعة، 120 مشاركة/10 دقائق إجمالًا)، فعدد الرسائل محدود بالسقف نفسه.

## خطوات التفعيل (بعد موافقتك)
1. إنشاء البوت وإضافته للمجموعة الإدارية والحصول على `chat_id`.
2. نشر الدالة: `supabase functions deploy notify-telegram --no-verify-jwt` (أو من لوحة Supabase).
3. إضافة الأسرار الثلاثة.
4. إنشاء Webhook لكل جدول (INSERT) يشير إلى رابط الدالة مع ترويسة `x-webhook-secret`.
5. اختبار بمشاركة وهمية.
